# Music Store SQL Analysis Project

## Project Overview
This project contains SQL queries written on a Music Store database dataset using PostgreSQL and pgAdmin. The goal of this project is to practice SQL concepts such as:

- SELECT statements
- WHERE clause
- GROUP BY
- ORDER BY
- Aggregate Functions
- JOINS
- Subqueries
- Common Table Expressions (CTEs)
- Business Problem Solving using SQL

The project includes beginner to advanced level SQL questions and solutions.

---

# Database Schema

The dataset contains multiple related tables such as:

- Artist
- Album
- Track
- Genre
- MediaType
- Playlist
- PlaylistTrack
- Employee
- Customer
- Invoice
- InvoiceLine

These tables are connected using primary keys and foreign keys.
